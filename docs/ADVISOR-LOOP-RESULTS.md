# 顾问闭环候选：实现与实际验证

本地修订 **advisor-loop-1**，基线 **round305-baseline-1**。仍是路线A：同弱模型提供可用解题内容，提高实际产物；原意和授权是边界。完整计划见 [PLAN-ADVISOR-LOOP.md](PLAN-ADVISOR-LOOP.md)。本轮没有重设计优化器核心/三档，没有修改用户模型或权限，也没有提交或发布。

## 结果与限制

三个闭环已实现并通过真实入口验证：主张对应的证据依赖、实际观察过的贡献/前版比较、独立逐轮交付状态。另修复原生模型响应回灌丢失，真实Flash两轮读取已经跑通。它不是靠增加提醒或强制咨询次数取得的结果。

自然任务对照有**有效但有限的探索证据**：改进后的《相位花园》形成相位差—合振幅—拍频—图像联动，较共享原稿有可观察增量；历史基线顾问同样带来有效改善。原候选报告曾格式失败，后验机械恢复同一意见后才完成改稿，因此不能称为干净的预登记胜利，不能证明候选普遍强于历史版或稳定降本。

当前运行进程仍是历史基线，尚未重启加载候选。新GUI状态未在已认证的现有页面实测；原URL无凭据读取返回401，没有绕过登录或启动替代服务器。

## 一、实际实现

### 证据结论不再被无关材料一票否决

- 新 [host证据层](../po06/lib/advisor-evidence.js)重新计算每条检查实际引用的内容，替换模型自报assessment/bindings。未引用的补充截断/缺失保留警告，不否决明确局部事实。
- 被引用的截断F材料仍不能通过，必须真实完整读取相关选择。原截断F0不污染独立完整read:path；混合截断/完整/失败/拒绝或不同版本的同名read引用明确歧义，不让一次成功掩盖其它不确定观察。
- 依赖和版本由 [阶段](../po06/lib/advisor-stages.js)、[覆盖](../po06/lib/advisor-coverage.js)共同持久化和复核。显式subjectPaths绑定实际成果，普通补充附件不自动变成新验收目标。老快照仍保守；坏或未知新格式不能放行。
- general整请求与delivery覆盖边界继续保守。内容被读到、hash相同、标签runtime-log，都不等于语义正确或真实运行已证实。

### 先独立看图，仅在有信息增益时补源码

[图像流程](../po06/lib/advisor-visual.js)首轮只见原任务、对象、已声明检查点和真实图像，不见执行者自评、源码或测试全绿。精确实现问题或具体缺陷追因需要时，才进入已授权源码/测量支持；正面findings本身不触发额外调用。

第二阶段不能抹掉首轮可见失败、缺视角和未执行行为。第二阶段JSON、引用、provider或适配器异常时，首轮负面/不确定观察仍作为诊断进入阶段/覆盖；正面观察降成未验证，不能因失败调用重置问题。两阶段共享原有轮次控制与取消，不加默认总截止。

### 把具体贡献带到当前执行，自动保留真实前版

[贡献记忆](../po06/lib/advisor-contribution-memory.js)只保存本次**实际已发送**的片段和不可变附件引用，不为缓存偷读整文件。复用要求同会话、human请求、工作目录、对象路径集合及focus；不同任务、权限、对象或焦点不串。

当前上下文能带入可直接用的贡献内容，后续有写入变化时只提示比较，不把文件不同叫采用成功或质量提高。后续改进能看到真实改前观察；无采纳表、无必须照做、无将质量建议绑成验收check。keep合法且非通过。缓存有容量边界、原子保存与坏数据校验；英文协作不复用旧中文内部叙述，也不额外翻译。

### 独立逐轮显示交付状态

使用已核实的additive conversation.chat.turnTail插槽及 [受信API](../po06/lib/control-api.js)，按session和实际事件seq重建 [该轮状态](../po06/lib/advisor-delivery.js)。只使用真实对应工具结果，不读Done作裁决，不用未来轮次覆盖旧答复。

显示已知缺陷／待验证／仅所列范围复核／没有复核，贡献另列建议或收益待比较。相同依赖文件不代表相同成果；只有精确目标与新鲜证据的修复才关闭旧失败。没有读取权限时不能洗白。历史会话通过宿主inspect只读加载，不恢复agent、不调用模型；只共享在途检查，刷新重新读取。

它不拦文件分享、不替换答复、不自动续跑，也不能保证模型永不写做好了。UI每次绑定读一次，可手动刷新，不后台轮询所有旧轮。

### 实际发现的可靠性修复

- [读取循环](../po06/lib/read-tools.js)保留SDK原生reasoning/text/tool块与回放签名。原来只重建tool-call，丢失当前Messages路由的原生回放内容。本地真实SDK序列化＋真实Flash/max两轮value17诊断成功；不能据此认定此前每次503都由它造成。
- [顾问流结尾](../po06/lib/advisor-stream.js)的显式error/aborted/max-tokens不能被有效JSON盖成通过；两阶段每次用量、缺报次数均合计。优化器默认drain未改。
- provider后续失败保留实读轨迹和已报告usage，未知不记零。
- 仅贡献报告支持极窄、可记录的语法恢复：字符串之外、闭合数组/对象后的唯一多余引号，且删除后整份JSON通过schema和引用检查。所有值不变，零新模型调用。验收报告不修，其它损坏仍失败；不是任意JSON猜修器。

## 三、自然任务：相位花园

[预登记](../.po06-tmp/advisor-loop-natural-preregister.json)在输出前固定：完全离线单HTML交互科普，频率/振幅/相位联动，暂停/继续/重置，准确解释相长/相消/拍频，桌面/手机/键盘可用。不是坦克题，没有写入产品领域模板。

- 共享一份原稿，原始请求/源码/真实截图/观测相同；基线与候选同官方Flash/max，各一份有效或失败意见＋至多一次改稿，不按质量挑选。
- 初次与一次对称传输恢复遇503、尚未形成意见。发现原生回灌缺口后，对两臂同样补协议兼容再各一次，避免把基线协议故障当对照优势。
- 基线最终意见有效；候选原始响应完整，但assumptions数组后多一个结构外引号，严格解析失败。该**主结果仍保留失败**。本地窄恢复只删同一字符，意见值、引用不变，完整校验通过；使用同一意见作单独标注的后验探索改稿，没有重新咨询或挑建议。
- 一个本地实验脚本因显示截断复制在请求前语法失败，已从完整原源恢复后先语法检查，未产生模型费用。
- 三份HTML提取只移除文档外说明，没有手工修成品代码。
