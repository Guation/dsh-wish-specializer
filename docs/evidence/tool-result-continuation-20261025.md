# 工具结果回灌回归修复

日期：2026-10-25。修复目标：恢复同一优化对话的正常收尾，撤销 a7768e1 新增的无工具整轮重生成，不添加新生产分支。

## 实际断点

两条现场记录位于 po06-wire.jsonl 第 5741 / 5768 行。模型调用 run，命令含 command -v、which、重定向或项目根之外路径；虚拟文件查询器按约定拒绝了调用。错误不是“没有随机生成出 JSON”，而是代码把拒绝结果回填后立刻退出，模型从未收到下一次请求来读取它：

请求工具 → 执行并拒绝 → 将 assistant 和 tool 结果加入内存对话 → break → 返回 finish=tool-calls → 外层终态校验失败。

拒绝本来是工具结果，不是模型最终输出。a7768e1 从原始输入启动第二个无工具请求，扔掉了刚建立的工具对话，掩盖了这个断点，现已撤销。

## 修复后的唯一流程

- 开始前确认能构造宿主工具结果消息，否则明确失败且不发起模型请求。
- 正常工具结果继续同一对话；任一调用被拒绝时，保留整批成功/失败结果并关闭后续查证。
- 模型在相同 system、原始输入、原 assistant 调用、所有匹配 ID 的工具结果之后给最终回答。保留原思考块和 replay/signature，不重建一份只含原话的请求。
- 轮次或查证预算达到上限也通过同样收尾完成；最终轮仍请求工具则明确失败，不执行或重启。
- 取消后不启动最终轮；用量累加所有实际工具轮。run 工具说明明确它是根目录内虚拟文件查询，不是可探测宿主安装环境的系统 shell。
