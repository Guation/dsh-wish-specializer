# 方向增强 v4：待真实会话验证的本地实现

> 本文件保留v4的历史行为与验证。当前实验实现已收敛为[固定快速开关v5](INFERENCE-FAST-ONLY.md)，不再提供其它档位或串行追加轮数。

本轮针对两个实际案例实施通用机制修复。原工作模型仍决定选用、组合或忽略方向；不恢复独立择优裁判，不修改用户工作模型、授权或两份案例产物。版本标识为推理协议 4，包发布版本仍为 0.8.4-stable；本轮不发布。

## 最终行为

- 方向使用独立系统角色，原任务、系统约束节选和最近公共工具/答复被作为引用数据提供。总公共正文预算 24000 字符，显式记录节选；不将私有 reasoning 或 provider replayState 送给方向。实际工作请求保留全部原始消息对象、模型档位、工具、输出上限和原生流。
- 方向档位独立选择目录支持的 off/none/minimal/low。快速优先关闭推理且上限 1024；均衡/完整轮数优先轻推理且上限 4096。没有可信轻档信息时保留原路由、说明未知/受限，不猜档位或提高一个更小的原输出上限。
- 初始方向并发；快速无追加方向轮次，均衡最多一轮，完整轮数保留请求轮数，但方向单次等待 15 秒、总准备 30 秒，随后保留已取得的有效方向继续。时间限制只约束方向阶段，依赖适配器响应取消；主工作生成不受其限制，也不会因超时重放工具。
- 伪工具协议（含 DSML/XML/结构化调用）、代码围栏、明显完整实现/程序和交付报告不能作为方向交接。拒绝有原因记录，不拼接坏输出的“可用部分”；语义伪装无法被确定性规则穷尽。
- 每步使用真实 native/PTC 工具事件中的来源编号、已报告失败和可确定对象版本。模型自己的文字、伪工具方向、顾问建议不成为已执行证据。FAIL 与 ALL PASS 同时出现时，各自范围分别保留；复合命令 stderr 的 SyntaxError 等不会被最终 exit 0 掩盖。
- 已报告失败将方向改为竞争假说与能区分它们的最小观察；并行方向分别侧重未证前提、内部状态到可观察结果的接口、仪器与实现的独立对照，避免三个完全相同的提示。原模型先判断与当前任务的关系，过去的调用错误不会自动成为成品缺陷或新的用户要求。
- 未闭合观察在同会话、同真实用户输入的多个步骤间持续。新真实用户输入开始新证据轮次。工具/检查身份/完整对象不匹配、旧结果、未知原始版本、读取关闭/越界/过大或文件变化，均不自动当通过。已知对象改变后，需要新鲜同检查同工具同对象复测；历史 seed 不回填现在的哈希。该记忆始终 completionClaimAllowed:false，不自动批准或阻止交付。
- 原方向均被拒时，真实失败背景仍可单独交给原模型。纯回复循环也接收相同背景；原有循环内部比较保持原行为，未新增一个证据裁判调用。

## 已取得的验证

本地定向：153 项，152 通过、0 失败、1 跳过。跳过项为 Windows 拒绝创建文件符号链接；相关 readBounded 路径守卫复用现有实现，该运行场景未得到本机验证。完整非浏览器：106 套成功；verifier-html.test.mjs 未计入，未宣称真实浏览器 UI 交互通过。

两个实际会话的 271 条曾交接方向离线重放：最新 44 条与旧案例 41 条伪工具协议全部被拒；还拒绝了 8 条程序/交付报告；可用技术提要仍保留。最新 E1179 的 spacing varies 在后续 ALL PASS 之后继续存在。原成品哈希不变。见 [重放结果](evidence/INFERENCE-V4-REPLAY.json)。

真实模型仅 DeepSeek Flash。使用临时 uniqueBy 函数夹具：本地先运行出真实失败与子集通过，驱动器封装工具事件；模型只生成一次实际 write 提议，驱动器应用并复测 8 项行为，验证闭合链条。它是 API/机制烟测，不是完整真实用户会话或通用质量比较。

| 观察 | 有效方向 | 拒绝 | 实际主模型 | 行为检查 | 总耗时 |
|---|---:|---:|---|---|---:|
| 最初 inherit，尚无时间护栏 | 5 | 1（77.6 秒传输停顿） | Flash max | 8/8 | 105.631 s |

最终 inherit 的约 20 秒在正常主生成；总准备限制并不限制它。不同调用的服务商延迟和内容变化很大，不能把这三次当因果速度对照或成品质量提升证明。首轮未被隐藏，增加时间护栏后才各配置验证一次。

完整绑定、原始结果文件引用及源码哈希见 [验证记录](evidence/INFERENCE-V4-VERIFICATION.json)。独立 Flash 工具复核因引用了不存在的入口路径而被拒，未计作通过；原始建议中的 skip/unknown 疑点已用额外回归排除，未知档位与 GUI 尚未加载的限制照实保留。正式阶段状态仍为未验证，不能把这次引用失败包装成独立验收通过。
