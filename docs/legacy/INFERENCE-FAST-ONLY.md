# 实验增强：固定快速开关（v5）

本地实验分支 `experiment/reasoning-latency-1`，未合并/发布。依据用户决定，机制只保留快速的开启/关闭；默认关闭，固定默认配置为 hybrid / 3方向 / 3轮口径 / fast。

## 固定3+3的实际含义

沿用真实会话测过的快速行为：正常一次工作生成前并发准备三份简短公共方向，再让原工作模型选用、组合或忽略并正常执行；同一步不做串行追加方向改写，不生成多份完整实现，也没有独立择优裁判。3+3不是宣称实际跑了三轮纠错。正常最多3份方向+1次主生成；关闭时不进入增强或证据查询路径。

旧的 parallel/loop/hybrid、balanced/inherit、2份方向或其它轮数设置在全局/会话的读取与写入都归一到固定快速配置，有明确迁移问题记录；不改 boost/English 布尔意图、用户模型、思考档位表、读取权限或其它辅助设置。设置持久化仍有原子写/备份。修复了保留其它重度会话时，仅切当前增强开关却会激活全局辅助的副作用。

## 已落地优化

1. **删慢路径**：引擎删除完整回复循环、反馈选择器及串行方向改写逻辑，任何旧配置都不能复活它们。方向优先目录声明的 off/none；缺失时只用支持的轻档/有界回退，不偷偷降低主模型。原始工作上下文、原生消息/replayState、工具及流式输出保留。
2. **近期证据接线修复**：recentEvidence 正式进入方向与交接，保留 source/check/kind/对象/版本及 bounded 原文；给最新实际结果预留位置。旧错误不再挤掉所有新观察；无关PASS仍不关闭旧失败。
3. **关注视图而非洗白记录**：新调用错误只提示一次，主模型完整且有实际可见内容地正常完成后才记“已交接”；失败/取消/空输出不消耗。之后转为retainedIncidents，原openIssues不变，不叫修复或验收通过。真实reported-failure及遗漏失败明细持续active，直到原有真实证据规则闭合。关注记录按会话/真实用户轮次隔离并有界持久化，重启不反复追同一错误；损坏时保守重发并披露。并发在飞请求可能同时收到同一新事件。
4. **误拒修复**：真实方向只在普通段落中以单反引号提到一个script标签，会被v4误当完整程序。现在只对这种孤立标签引用做窄豁免；真实脚本正文、多标签HTML、原始HTML、完整程序、DSML及私有控制协议仍被拒绝。不是放松成品实现或工具执行边界。
5. **更短的方向目标**：只请求一条对当前任务有用的公开思路，不要求把历史E编号逐项审计；当前真实失败才启动区分性反证，历史调用事件不成为新增待办/交付阻止门。原模型继续自主决定采用哪些建议。

## 真实证据与限度

定向回归191项：190通过、0失败、1跳过（Windows不允许创建符号链接的运行场景）。108套非浏览器套件全部成功，原始结果见 [验证记录](evidence/INFERENCE-FAST-ONLY-VERIFICATION.json)；不把 verifier-html 浏览器套件算通过。独立Flash复核未发现所审快速链路实质缺陷，K2/K3/K4有支持；K1因当前GUI未重载/未实机审界面保留未验证，整体不记为已通过验收。

对126组已保存真实v4快照做固定轨迹离线回放：快速案例反证模式从51/58降为5/58，完整轮数案例从61/68降为13/68；所有原始待核对记录逐字保持，未闭合产品检查的补充用例仍每次active。E387历史调用+E421成功结果现在同时进入正确范围；后者不会替前者直接关闭。两份原成品哈希不变。见 [回放](evidence/INFERENCE-FAST-ONLY-REPLAY.json)。

以相同真实方向正文对照归档的8a34057：38条不再因单独的行内标签引用而被误判完整程序，其中快速案例28条、完整轮数案例10条；未新增拒绝。这是过滤形态的改进，不代表38条都事实正确或会被主模型采用。见 [同文本对照](evidence/INFERENCE-FAST-ONLY-FILTER.json)。

真实模型只用DeepSeek Flash：一次固定快速API夹具，三次off方向+一次max主生成，三份方向均有正文且通过过滤；实际修复8/8行为检查通过，共9.751秒。此测试使用临时函数模块，不重做用户坦克作品，不当成稳定速度/质量提升。早期v4烟测与本轮文本/角色/过滤条件不同，不能直接拿耗时比率当提速证据。见 [Flash记录](evidence/INFERENCE-FAST-ONLY-FLASH.json)。
