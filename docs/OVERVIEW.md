# 当前总览（唯一状态入口）

本文件回答“**现在这个插件是什么状态、以谁为准**”。历史计划与过程记录只作追溯，冲突时以本文件 + 代码为准。

## 1. 产品是什么

许愿特化器（Wish Specializer，包名 `@dsh-external/dsh-wish-specializer`，API 前缀 `po06`）。
你的原话一个字不改地发出去，插件在**发送前**补三段方向性建议，交给工作 AI。

## 2. 注入文合同（当前）

```text
请优先考虑以下围绕目标提炼的重点建议……建议不覆盖用户明确要求，也不自动成为逐条必做的硬性要求。

【制作建议】
1. … 2. …

【临时脚手架建议】
1. … 2. …

【Ask用户(ask_user_question)】
1. …
```

- 三段合计 **3000 token** 上限（不是每段），是天花板而非配额；
- **制作建议**：决定成品水平的方向（审美、结构、材质、光影、交互、可信度）；
- **临时脚手架建议**：由优化 AI 结合目标思考什么临时能力能让工作 AI 做得更准、更省——
  判据是六件事：判断对错的通道是否可测量、改一处的牵连面、一次迭代的成本、
  反馈能否同条件复现、看不见的部分是否仪表化、能否一次生成多候选再比较；**无收益就留空**；
- **Ask**：只列确需确认的问题，**不给选项**，由工作模型调用 `ask_user_question` 自行组织选项；
- 所有条目是**方向性许愿**：不给代码、参数、命令、目录、接口或操作步骤；
- 优化器**不新增授权**，不替你拍板；原话仍是唯一权威。

细节与取舍见 [`SCAFFOLD-DIRECTIONS.md`](SCAFFOLD-DIRECTIONS.md)。

## 3. 已撤出的东西（别再复活）

| 撤出项 | 为什么 |
|---|---|
| 工具注册 / 任务级耐久索引 / 结果信封 | 那是另一项功能，不是“脚手架建议” |
| `firstUse` / `stopWhen` / 回报协议 | 会把许愿变成执行流程；停止条件已实测过：模型不会因此停手 |
| 关键词或正则兜底补 `inspect` | 宿主替模型填答案，不能代表优化 AI 的判断 |
| 按形态词整条删建议 | 粗暴；改为提示词纪律“问形态就不写死形态” |

历史实现保留在提交里，另有二进制补丁可恢复；详见 `CHANGELOG.md` 与本次 revert 提交。

## 4. 解析健壮性

- **结构配平修复**：括号错位或末尾缺收尾符时补齐，走 `recovered: bracket-repair` 并记 `json-bracket-repair:N`；
- **不编内容**：字符串未闭合（截断）→ 判失败并标 `repairRefused: unterminated-string`；纯散文 → 判失败；
- 旧规约“括号不配平一律不修”已于 2026-10-21 显式反转（一次手误曾作废整轮调用）。

## 5. 顾问（独立子系统）

顾问仍是“流程里的点拨节点”，不是验收闸门：两段式输出 ≤512 token、会话级台账先结旧账、
证据不足且影响大时提示工作模型调 ask。契约见 [`../po06/ADVISOR.md`](../po06/ADVISOR.md)。
