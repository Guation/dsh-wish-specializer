# 优化生产管线契约

状态：整体简化已实现，本地自动流程验证通过；真实用户的新版本现场复测待进行。本页定义生产目标；历史回归、模型冒烟和用户此前的局部复测不能证明本次重构已经通过真实用户验收。已确认的故障与证据见 [KNOWN-ISSUES.md](KNOWN-ISSUES.md)。

## 一条生产路径

`输入 → 可选只读工具 → v3 规范化 → 统一语言渲染 → ready / empty / failed → 同一 run 原子保存`

每会话只保留一个当前运行，以 `sessionId + runId` 标识，运行代次只用于拒绝乱序到达的旧请求。新运行中止并替代同会话旧运行；不同会话互不替代。运行开始时固定原话、上下文范围、模型、effort、语言、档位等设置快照，并持有一个 `AbortController`。这些设置在本轮固定；明确关闭辅助或改变本轮必需的语言模式会使在途运行作废，下一轮重新开始。

- 可选工具只在会话目录和允许的只读能力内采集依据。工具输出不是用户要求，不增加授权；失败如实记录。
- 模型结果只经一个 v3 规范化入口，再由一个渲染入口处理语言与正文。具体输入形状见 [OPTIMIZER-PROTOCOL.md](OPTIMIZER-PROTOCOL.md)。
- 正常生产不经过旧 reducer/compiler，也不因空结果启动 `retryEmpty`、补占位内容或回退到旧协议。不得用正则猜测正文是否“像有效包”来决定接受、重试或提交。
- 渲染完成后形成一份完整结果：运行身份、终态、最终 packet、原话与实际发送文本/语言来源，以及诊断信息。预览、上下文和卡片复用这份最终包；取用时不再替换标题、重新渲染或编译。

## 结果与写入

| 终态 | 含义 | 包与界面 |
| --- | --- | --- |
| `ready` | 有有效建议或待问问题 | 保存最终包；允许预览、确认，提交后可生成对应卡片 |
| `empty` | v3 结果有效，但没有辅助增量 | packet 为空；无前言、标题、占位或辅助卡片；不自动重试 |
| `failed` | 请求、必需结构或必需语言结果失败 | 留下真实错误；不把外壳或旧编译产物保存成成功包 |

写入前核对会话、当前 `runId` 与中止状态，完整结果作为一次提交保存。迟到结果、被替代运行或已中止运行都不能覆盖当前状态。`committed`、字符数非零或 HTTP 成功本身不证明建议正文存在。

切走会话不取消原会话任务。结果仍保存到发起会话；返回时恢复完整结果和同一 `runId`，不能仅恢复包正文而丢掉终态、来源或发送信息。

## 一次提交决定

客户端先从现有状态接口确认产线版本匹配；未知或不匹配时不拦截、不调用优化模型，保留原生发送与原话。自动完成、审查确认和切回会话后的恢复提交，统一使用 `POST /po06/api/packet`，携带同一 `runId` 和 `disposition: "send"`。提交前必须已有对应运行的 `ready`/`empty` 结果；禁止用旧包冒充本轮完成，也不使用 `GET /packet` 的 15 秒等待/轮询。审查中明确编辑的文本成为同一运行的最终包，随后各交付面使用相同文本。

| 动作 | 运行处理 | 实际发送 |
| --- | --- | --- |
| 自动 / 审查确认 / 恢复后发送 | 同一 `runId`，`disposition: "send"`，保存对应最终结果 | 本轮 outgoing；仅 `ready` 携带辅助包 |
| 跳过 / 双击 Enter 跳过 | 一次 `disposition: "skip"`；中止任务并清空本轮结果与辅助包 | 用户原话逐字发送；无包、无卡片；观察者不得再次优化 |
| 取消 | 中止任务并清空本轮结果与辅助包 | 不提交消息；输入框保留原话 |

跳过与取消都不允许迟到的流式完成事件重新填包或触发发送。观察者只消费与实际发送文本对应的明确提交，不另开优化或重新渲染；同会话的不相关消息不能领走待发送包。

## 英文与来源

英文模式沿用既有用户可见语义：原话独立保留为来源；开启时实际发给工作模型的 human 文本使用忠实英文任务，建议与任务翻译分开。代码、路径与精确字面量保留；用户指定的答复语言也保留。`empty` 只表示零辅助，不撤销有效任务翻译。跳过始终发送原话，取消始终不发。

协作基调功能已整体移除，包括普通/硬邦邦选择、风趣夸张改写及 `hardNote` / `hardOn` 尾注。用户报告 A/B 复测只在硬邦邦时触发问题，据此决定移除；这是用户报告的观察，未独立证明因果。既有 `TRANSPORT` 记录描述当次失败形式，没有排除该触发条件，也不证明两者独立。历史风格测试和测量保留原样，不代表当前功能或移除后的效果与时延。
