# 许愿特化器 · 产品规格

本页说明产品目标与边界。优化运行、结果保存和提交以 [OPTIMIZATION-PIPELINE.md](OPTIMIZATION-PIPELINE.md) 为主契约；整体重构已完成本地自动验证，现场复测以实际加载版本为准。本页替代此前 v0.8 的命令改写、旧策略回退与硬性 ask 闸门描述。

## 目标与输出

用户原话定义目标、约束与授权。插件围绕已有目标贡献方向建议，让工作模型理解哪些结果与工作能力值得优先考虑；不把机器理解改写成“用户明说”，也不替用户决定影响结果且无法合理推断的选择。

辅助按需呈现三类内容：制作建议、临时脚手架建议、Ask 用户。脚手架由优化模型结合实际任务和已有能力判断，参见 [SCAFFOLD-DIRECTIONS.md](SCAFFOLD-DIRECTIONS.md)。建议描述目的与价值，不规定代码、参数、命令或实现步骤；提问只提供问题，工作模型组织选项并调用 `ask_user_question`。没有有用内容时允许零增量，不填满栏目。

| 档位 | 目标 |
| --- | --- |
| 关闭 | 不生成优化辅助；英文转换遵循独立语言设置 |
| 轻度 | 简洁地指出最有价值的方向与必要澄清 |
| 标准 | 补足影响结果的关键方向，可用小例子说明效果 |
| 重度 | 更深入地贡献提升结果与迭代能力的方向，不变成实现方案 |

档位不承担固定条数配额。制作、脚手架和 Ask 合计 3000 token 是输出预算上限，不是必须填满的目标。语言、基调、模型、effort 与历史范围均是显式设置，随本轮快照固定。

## 来源与授权

- 原话独立、完整保留。英文模式可让实际发送的任务采用忠实译文；原话仍是来源，新增建议不混入任务翻译。
- 历史读取范围由用户的回合/全文设置决定，按预算降低呈现详细度；无法提供的内容显式说明，不编造上下文。
- 会话身份必须明确；不回落到会话列表第一项。可选工具只读当前会话目录允许的内容，目录列表不能冒充已经读过文件。
- 历史、文件与可用能力都是观察依据，不是新的用户命令。生成建议和 proposed 问题都不构成已授权、已提问、已同意或强制清单。

## 交付与判断

用户可选自动或审查；界面动作及发送文本见 [DELIVERY.md](DELIVERY.md)。最终包由预览、上下文和卡片共同使用，不能各自再加工。跳过原文发送，取消不发送。

正确性看原意与来源是否保留、建议是否完整、空包是否零注入、运行与会话是否一致。真实价值仍需同任务对照和用户判断；格式、字数、自评分或旧版套件通过数不能证明更好。既有 benchmark 及其局限见 [评测总账](../po06/eval/BENCH-TOTAL-0.9.0-beta-1.md)，本次重构不改写该证据。
